# Code of Conduct

## The short version

Be decent. This is a word game.

## What is expected

- Assume good faith, especially across a language barrier. Most contributors
  here are writing in their second or third language.
- Correct facts, not people. "That reading is wrong, `蓮` is `はす`" is helpful.
  "You clearly do not speak Japanese" is not.
- Disagree about the work. A rejected pull request is about the code or the
  words, never about the person who sent it.

## What is not acceptable

Harassment, insults, or demeaning comments; discrimination on any basis
including nationality, native language, or fluency; publishing others' private
information; sustained disruption of discussions; sexual attention or imagery.

This applies in issues, pull requests, commit messages, and any other project
space.

## Reporting

Report problems by opening an issue, or privately to the repository owner
through their GitHub profile. Reports are handled confidentially.

Maintainers may edit or remove contributions that violate this document, and
may block accounts for repeated or serious violations. Enforcement decisions
are explained to the person affected.

## Scope

This applies to project spaces and to public spaces when someone is
representing the project.
